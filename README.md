# UsedBookWebstore



## About
The UsedBookWebstore is a web application designed for managing and selling used books. This project aims to provide a simple and user-friendly platform where users can browse, purchase, and possibly sell second-hand books. Built using modern web technologies, it leverages ASP.NET Core and Entity Framework Core for a robust backend, with a focus on scalability and ease of maintenance.


## Features 

- User authentication and authorization using ASP.NET Core Authentication.

- Book catalog management with Entity Framework Core.

- Integration with SQL Server for data persistence.

- Real-time bidirectional communication across the web using SignalR.

- Tools for managing NuGet packages and visual studio solutions.



## Tech Stack

- ASP.NET Core: The foundational web development framework for the application, providing high performance and cross-platform support.
- ASP.NET Core Authentication: User authentication and authorization for secure access.
- ASP.NET Core Identity with Entity Framework Core: Identity service that uses Entity Framework Core for database-based user management.
- Entity Framework Core: Object-relational mapping (ORM) for simplifying database operations, with SQL Server support.
- Entity Framework Core SQL Server: Specific database provider for connecting to SQL Server.
- Entity Framework Core Tools: Tools for managing migrations and updating the database schema.
- SignalR by Microsoft: Real-time, bidirectional communication between the web application and clients.
- Swashbuckle.AspNetCore by maindivender: Swagger tools for documenting and testing APIs in ASP.NET Core.
